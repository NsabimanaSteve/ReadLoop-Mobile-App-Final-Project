**Create a complete mobile app prototype for "ReadLoop" - a reading habit building and social reading application. I need you to design all screens and assess the user experience.**

## 🎯 PROJECT OVERVIEW:
ReadLoop is a comprehensive mobile app that helps users build reading habits while connecting with other readers through social reading circles. The app combines personal progress tracking with community engagement.

## 📱 SCREENS TO DESIGN:

### 1. **Onboarding & Authentication**
- Welcome screen with app logo and tagline "Build Your Reading Journey"
- Sign up screen (email, password, display name)
- Login screen with "Forgot password" option
- Quick tutorial screens (3-4 screens explaining key features)

### 2. **Home Dashboard**
- Welcome header with user name and daily progress
- Reading stats cards (current streak, books read, pages today, weekly goal %)
- Currently reading book card with progress bar
- Quick action buttons ("Add Book", "Join Circle")
- Recent activity feed

### 3. **Books Library**
- Search bar with filter options
- Book grid layout (2 columns)
- Book cards showing cover, title, author, status badge
- Filter tabs (All, Reading, Finished, Want to Read)
- Floating action button to add new book
- Book detail screen with progress tracking

### 4. **Reading Circles**
- List of reading circles with member count and privacy status
- Create new circle form
- Circle detail screen with book info, members, discussions
- Join circle interface
- Map view for nearby circles (location-based)

### 5. **Profile & Settings**
- User profile with avatar, name, email
- Reading goals section (daily/weekly targets)
- Achievement badges and streaks
- Settings menu (notifications, privacy, about)
- Statistics and reading history

### 6. **Additional Screens**
- Book detail/edit screen
- Circle creation wizard
- Discussion forum interface
- Achievement/unlock celebration screens
- Offline mode indicator

## 🎨 DESIGN REQUIREMENTS:

### **Visual Style:**
- **Primary Colors**: Calming blues (#2196F3, #1976D2) and greens (#4CAF50)
- **Accent Colors**: Orange (#FF9800) for achievements, Purple (#9C27B0) for progress
- **Typography**: Modern, readable fonts (Roboto or similar)
- **Design System**: Material Design 3 principles
- **Theme**: Clean, minimal, reading-focused

### **UI Elements:**
- **Bottom Navigation**: Home, Books, Circles, Profile icons
- **Cards**: Rounded corners, subtle shadows, clean layout
- **Progress Indicators**: Linear progress bars, circular progress
- **Buttons**: Primary (filled), Secondary (outlined), Floating action buttons
- **Forms**: Clean input fields with proper validation states
- **Badges**: Status indicators, achievement icons

### **Layout Guidelines:**
- **Mobile-first**: 375x812px (iPhone X/11/12 dimensions)
- **Safe Areas**: Account for notches and rounded corners
- **Touch Targets**: Minimum 44px for interactive elements
- **Spacing**: Consistent 16px grid system
- **Hierarchy**: Clear visual hierarchy with proper contrast

## 🔧 INTERACTION DESIGN:

### **User Flows:**
1. **Onboarding Flow**: Welcome → Sign Up → Tutorial → Home
2. **Book Management**: Search → Add → Track → Complete
3. **Circle Flow**: Browse → Join → Participate → Discuss
4. **Goal Setting**: Profile → Set Goals → Track Progress → Achieve

### **Micro-interactions:**
- **Button States**: Hover, pressed, disabled
- **Loading States**: Skeleton screens, spinners
- **Success States**: Checkmarks, celebrations
- **Error States**: Clear error messages and recovery
- **Transitions**: Smooth screen transitions and animations

### **Gestures:**
- **Swipe**: Navigate between tabs, dismiss notifications
- **Pull to Refresh**: Update content lists
- **Long Press**: Context menus for books/circles
- **Tap**: Primary interaction method
